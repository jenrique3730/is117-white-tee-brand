
# FORME / 01 — A white tee, with intention

A premium minimalist classroom concept for the IS117 Brand Studio. FORME treats the plain white T-shirt as room for personal styling: show the object clearly, avoid assumptions, and let the visitor decide what it means in their everyday wardrobe.

> **AI-created proposal, pending learner review.** The name, audience hypotheses, promise, archetype, voice, and selected visual direction in this project were drafted by AI after the learner asked it to do the work. They are not presented as the learner's own choices or validated audience research.

## Project

- **Audience hypotheses:** everyday dresser seeking a repeatable wardrobe base; self-expression-focused dresser seeking a styling canvas.
- **Brand character:** Creator; precise, calm, open.
- **Design direction:** restrained modernist storefront, with a paired postmodernist study using the exact same offer.
- **Persuasion:** free styling note (reciprocity) and an optional identity invitation (unity), with no invented sales proof or urgency.
- **Product boundary:** white short-sleeved T-shirt illustration, demo sizes S/M/L/XL and fictional $28 price. No verified materials, fit, production, shipping, or sustainability claims; no checkout.

## Run locally

Requires Node.js 22.16+ (or 24+) and npm:

```sh
npm ci
npm run dev
```

Open the local address printed in the terminal. The size selector and temporary demo bag work without checkout. Run `npm run check` for the prepared project checks.
